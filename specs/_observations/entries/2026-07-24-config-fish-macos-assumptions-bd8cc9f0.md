- 2026-07-24 [dotfiles] roles/fish/files/fish/config.fish is heavily macOS-assuming and will error on every login shell on the Linux host once the fish role runs. Unguarded `brew --prefix` calls at lines 30-36, 45 and 86-88 (OPENSSL/ZLIB/SQLITE/READLINE/MYSQL/POSTGRESQL/MARIADB paths, GOROOT, and the brew bin/sbin fish_add_path entries) all invoke a command that does not exist on Linux, leaving the derived PKG_CONFIG_PATH/LDFLAGS/CPPFLAGS empty. Line 40 sets DYLD_FALLBACK_LIBRARY_PATH, a macOS-only concept. The SSH_AUTH_SOCK stabilization block at 113-121 hardcodes the macOS 1Password Group Containers socket path and has no Linux arm for ~/.1password/agent.sock, so tmux/ssh agent stabilization silently does nothing here. This is the single biggest remaining blocker to shell parity with the personal Mac and is core linux-migration Task 7 work. Fixing it needs an os-conditional restructure plus a macOS regression run, since REQ-D1.2 guarantees no behavior change on the Mac hosts.
