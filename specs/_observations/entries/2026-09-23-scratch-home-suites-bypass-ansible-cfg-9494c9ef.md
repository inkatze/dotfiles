- 2026-09-23 [dotfiles] The scratch-HOME role suites (credential-path-guard, planwright-marketplace, git-unattended-auth) run ansible-playbook from a scratch cwd with HOME overridden, so the repo ansible.cfg (inject_facts_as_vars = False, interpreter_python) never applies to them: a role that regresses to injected `ansible_<fact>` names passes all three suites and only fails on a real host or in the CI role matrix. The shared harness shape could export ANSIBLE_CONFIG=$repo/ansible.cfg (or copy it beside the scratch play) so the suites run under the production config.
