- 2026-09-21 [dotfiles] Testing a fish conf.d snippet against a real, non-scratch $HOME can regress the whole machine live: if the snippet is already symlinked into ~/.config/fish/conf.d from a different (already-materialized) checkout, writing experimental content to the machine-local pointer/config file it reads makes every new fish shell on the machine source that experimental content until restored. Use a fully scratch $HOME (with any needed fish functions stubbed or symlinked in) for this class of test, never the real pointer path.
