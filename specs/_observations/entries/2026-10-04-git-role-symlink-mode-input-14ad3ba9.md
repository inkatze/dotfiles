- 2026-10-04 [dotfiles] roles/git: when the repo-owned ~/.gitconfig symlink is replaced, the new file mode is derived from the deleted symlink own permissions (stat follow:false). Linux symlinks are always 0777, so that yields 0600; on macOS a symlink mode follows the umask, so an unusual umask such as 0277 would create ~/.gitconfig 0400 and break later git config --global writes. Defaulting to 0600 in the repo-symlink case would remove the dependency; the migration path also has no fixture case.
