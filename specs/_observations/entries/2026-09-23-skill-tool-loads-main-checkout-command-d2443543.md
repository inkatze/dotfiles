- 2026-09-23 [dotfiles] The Skill tool loads dotfiles-local commands (/panel-review, /code-review, ...) through the materialized ~/.claude/commands symlink, which follows the main checkout, so a worktree branch that edits a command file cannot exercise its own version through the tool; a review of a command file has to read the branch file directly and follow it by hand. Worth a per-worktree override or a documented workaround before the next command-file PR.
