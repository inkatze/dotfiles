- 2026-08-05 [dotfiles] planwright dispatches every worker with LC_ALL=C exported into its environment: both scripts/fleet-streamjson.sh (line 123) and scripts/fleet-dispatch-env.sh (line 73) set and EXPORT it, correctly for their own POSIX-sh charset determinism, but the exported value is inherited by the launched claude process and everything it spawns, including the project CI the worker runs. Locale-sensitive project tooling then fails in the worker and only in the worker: reproduced here with ansible-lint, which under LC_ALL=C dies with subprocess.CalledProcessError on `ansible-config dump`, while `mise run lint` is green in an ordinary worktree on the same commit. The failure is invisible to the human, who never reproduces it from their own terminal, and it presents as the task breaking CI rather than as an environment defect. Fix direction: scope LC_ALL=C to the scripts own execution rather than exporting it across the dispatch boundary, or restore a UTF-8 locale in the launch environment the worker receives.
