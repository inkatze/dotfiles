- 2026-09-21 [dotfiles] GNU and BSD stat disagree on -f: GNU reads it as --file-system, so `stat -f <format> <file>` on Linux treats the format string as a filename, prints filesystem info for the real file and exits 0. A `stat -f ... || stat -c ...` fallback therefore never reaches the GNU branch and yields a multi-line block instead of a mode; a mode comparison passes on macOS and fails in CI. Every sync script here already orders GNU first (stat -c then stat -f), which is the correct direction since BSD has no -c and genuinely errors. Separately, scripts/ssh-lan-config-sync-test.sh uses bare `stat -c` with no fallback, so it is silently Linux-only; it is wired into neither CI nor lefthook today, so nothing catches that.
