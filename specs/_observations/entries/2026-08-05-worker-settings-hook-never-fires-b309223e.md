- 2026-08-05 [dotfiles] The worker-command-guard auto-approve hook in config/worker-settings.json is wired as "${CLAUDE_PLUGIN_ROOT}"/scripts/worker-command-guard.sh, but CLAUDE_PLUGIN_ROOT is injected by the plugin system for plugin-declared hooks and is NOT interpolated when the fragment is passed to a worker via --settings. Exporting the variable into the launching environment does not help either. Result: the hook silently never fires, the worker falls back to the narrow prefix allowlist, and an unattended stream-json worker deadlocks on its first compound command with no diagnostic anywhere. Confirmed by proving worker-command-guard.sh returns permissionDecision allow for the exact command the worker was blocked on. Hardcoding the absolute path in an adopter overlay fixes it and visibly changed behavior. Suggest the fragment ship a resolved path or the launcher rewrite the stanza at dispatch.
