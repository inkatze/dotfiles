- 2026-09-21 [dotfiles] Replacing an in-place redirect write with the atomic mktemp+mv idiom silently changes the target file mode: a redirect to an existing file preserves its mode, while mv installs the temp file, which mktemp creates 0600. Measured on ~/.claude/settings.json going 0644 -> 0600 with no chmod anywhere in the script. Tightening happened to be the right outcome for that file, but the mechanism was invisible and the opposite case (a file that must stay group-readable) would break just as quietly. Any mktemp+mv conversion should assert the mode it wants explicitly rather than inherit mktemp default.
