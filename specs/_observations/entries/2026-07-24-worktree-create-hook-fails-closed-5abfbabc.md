- 2026-07-24 [planwright] On this Linux host, Agent-tool worktree isolation is unusable: every dispatch with isolation=worktree fails with "WorktreeCreate hook failed: hook succeeded but returned no worktree path". The hook is planwright plugin-supplied (hooks/hooks.json wires WorktreeCreate to scripts/fleet-worktree-track.sh hook-create), and that script documents itself as a strict pass-through that echoes the stdin worktree_path and fails CLOSED — echoing nothing refuses creation. So the refusal is by design, but the trigger is not obvious: it means hook-create could not extract or validate worktree_path from its stdin payload on this host. Operational impact: /offload cannot use the subagent rung with isolation, forcing sequential dispatch when two workers would otherwise run in parallel on disjoint files, since they must then share one checkout and would contend on git branch operations. Worth checking whether the hook-create stdin contract matches what this harness version sends.
