- 2026-08-10 [dotfiles] mise ls --missing <tool> prints nothing both when the tool is installed and when it is merely undeclared (verified with an uninstalled, undeclared deno), so any Ansible gate built on it cannot tell convergence from a missing config symlink. One such gate was written and removed within this branch. Worth knowing before the idiom is reached for again; mise ls --installed is no better, since it resolves registry entries rather than local installs.
